Bluetooth Relay Automator

This is a simple Android app that allows you to automate the process of connecting to and disconnecting from Bluetooth relays, including custom macros for automating tasks like opening garage door, switching lights on and off, etc.

For a detailed description of the Android app, see the repository on GitHub: https://github.com/neckarhackerapps/bluetoothrelayautomator
